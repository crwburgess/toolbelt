# Toolbelt: free AI prompts

Free prompts for Claude and other AI assistants, rewritten from agents I use in my own business. No sign up, nothing to install. Copy one, paste it into your assistant, and it tells you what it needs.

Every prompt works the way I do with clients. It starts by asking about your situation, then works through the problem with you step by step, so you can follow the reasoning and shape the outcome. It shows where every finding comes from, puts the result in a document you can keep, and lets you stop whenever you have what you need and pick up later where you left off.

I'm [Chris Burgess](https://crwburgess.com/?ref=github), a fractional CPO for engineering-led companies. You can also browse them on [my toolbelt page](https://crwburgess.com/toolbelt/?ref=github).

## Using them

They work in Claude, ChatGPT or any other assistant. If a prompt needs something switched on, such as web search or code execution, it tells you when it needs it.
